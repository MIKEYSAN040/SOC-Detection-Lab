# Attack Analysis

## Attack Behavior

MSHTA is a legitimate Windows utility that can execute
Microsoft HTML Applications (HTA).

Attackers can abuse mshta.exe as a signed Microsoft binary
to execute malicious content.

## Detection Objective

Detect execution of mshta.exe and provide analysts with
process context for investigation.

## ATT&CK Mapping

Technique:
T1218.005 — Mshta

Tactic:
Defense Evasion

## Why This Behavior Matters

The execution of mshta.exe is not inherently malicious.
Therefore, the detection should be investigated using
command-line arguments, parent process, user, and related
activity.

## Expected Evidence

Sysmon Event ID 1 — Process Creation

Important fields:

- Image
- CommandLine
- ParentImage
- ParentCommandLine
- User
