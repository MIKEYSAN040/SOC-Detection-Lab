/*
Detection: Suspicious MSHTA Execution

Data Source:
The EVTX attack sample was imported into Splunk Enterprise
using the dedicated "evtx_attack" index.

EventCode=1:
Sysmon Event ID 1 represents Process Creation events.
This event is relevant because the Sigma rule detects
execution of a process (mshta.exe).

Image:
The Sigma condition Image|endswith: '\mshta.exe' is
translated into a Splunk wildcard match for mshta.exe.
*/

/* Detection Query */
index=evtx_attack EventCode=1 Image="*\\mshta.exe"
/*
Investigation Query:
The following fields were selected to provide process
context for analyst triage, including the executing user,
command line, parent process, and process IDs.
*/

index=evtx_attack EventCode=1 Image="*\\mshta.exe"
| table _time host User Image CommandLine ParentImage ParentCommandLine ProcessId ParentProcessId
