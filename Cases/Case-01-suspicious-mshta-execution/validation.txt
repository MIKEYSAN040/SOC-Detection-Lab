# Detection Validation

## Environment

SIEM:
Splunk Enterprise

Dataset:
EVTX-ATTACK-SAMPLES

Attack Sample:
sysmon_mshta_sharpshooter_stageless_meterpreter.evtx

## Validation Process

1. Selected an MSHTA attack sample.
2. Imported the EVTX data into Splunk.
3. Identified Sysmon Process Creation events.
4. Created a Sigma detection.
5. Converted Sigma to Splunk SPL.
6. Executed the SPL against the imported dataset.
7. Confirmed a matching mshta.exe process event.
8. Investigated process context.

## Detection Result


The detection successfully identified the expected
MSHTA process creation event.

## Classification

Verdict:
True Positive

## False Positives

- Legitimate HTA applications
- Administrative scripts
