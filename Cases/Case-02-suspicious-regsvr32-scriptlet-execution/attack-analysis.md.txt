# Attack Analysis

## Overview

Regsvr32.exe is a legitimate Microsoft-signed Windows utility used to register and unregister COM components. Because it is a trusted operating system binary, attackers frequently abuse it as a Living-off-the-Land Binary (LOLBIN) to evade security controls.

One of the most common abuse techniques is known as **Squiblydoo**, where Regsvr32 loads `scrobj.dll` and retrieves a remote scriptlet using the `/i:` parameter. The scriptlet is executed without requiring a traditional executable to be written to disk, allowing attackers to bypass application whitelisting and reduce their forensic footprint.

---

## Observed Behavior

The imported Sysmon event shows:

- Execution of `regsvr32.exe`
- Use of the `/i:` parameter
- Loading of `scrobj.dll`
- Retrieval of content from a remote HTTP URL hosted on Pastebin

The use of a public Pastebin URL significantly increases the confidence that this activity is malicious, as enterprise administrators rarely host legitimate COM installation scriptlets on public paste-sharing services.

---

## Why This Activity Is Suspicious

The detection is not based solely on the execution of Regsvr32.

Instead, multiple indicators are correlated:

- Regsvr32 execution
- Remote HTTP URL
- Scriptlet execution (`scrobj.dll`)
- `/i:` installation parameter

Individually, some of these indicators may be legitimate.

Together, they strongly align with the Squiblydoo attack technique documented by MITRE ATT&CK.
