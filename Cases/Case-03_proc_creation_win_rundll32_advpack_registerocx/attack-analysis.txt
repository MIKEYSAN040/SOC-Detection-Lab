# Attack Analysis

## Overview

Rundll32.exe is a legitimate Microsoft-signed Windows binary used to execute exported functions from Dynamic Link Libraries (DLLs). Because it is trusted by Windows, attackers frequently abuse Rundll32 as a Living-off-the-Land Binary (LOLBIN) to execute malicious code while bypassing security controls.

One known abuse technique involves invoking **advpack.dll,RegisterOCX**, which allows attackers to proxy execution through a trusted Windows binary.

---

## Observed Behavior

The imported Sysmon event shows:

- Execution of `rundll32.exe`
- Invocation of `advpack.dll,RegisterOCX`
- Execution initiated by `cmd.exe`
- Sysmon Event ID 1 (Process Creation)

---

## Why This Activity Is Suspicious

The detection is not based solely on the execution of Rundll32.

Instead, multiple indicators are correlated:

- Rundll32 execution
- advpack.dll invocation
- RegisterOCX function call
- Parent process is cmd.exe

Together, these indicators strongly suggest abuse of a trusted Windows binary for proxy execution.
