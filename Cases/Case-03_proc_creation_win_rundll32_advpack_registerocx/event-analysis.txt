# Event Analysis

## Summary

The imported Sysmon Process Creation event recorded the execution of Rundll32 initiated from the Windows command interpreter.

---

## Important Event Fields

| Field | Value |
|--------|-------|
| Event ID | 1 |
| Image | C:\Windows\System32\rundll32.exe |
| Parent Image | C:\Windows\System32\cmd.exe |
| Suspicious Command | advpack.dll,RegisterOCX c:\Windows\System32\calc.exe |

---

## Analysis

The event indicates that the trusted Windows binary **rundll32.exe** executed the **RegisterOCX** function from **advpack.dll**.

The parent process was **cmd.exe**, indicating that the execution originated from the Windows command interpreter rather than normal user activity.

Although the execution arguments were not available as an extracted field after ingestion, the raw Sysmon event clearly contained the suspicious command, which was used during validation.

This behavior is consistent with abuse of Rundll32 for proxy execution and maps to **MITRE ATT&CK T1218.011**.

---

## Conclusion

The Sigma detection successfully identified suspicious Rundll32 execution associated with the **advpack.dll RegisterOCX** technique.

The detection was validated using both extracted process creation fields and raw event analysis, ensuring accurate identification despite ingestion limitations.
