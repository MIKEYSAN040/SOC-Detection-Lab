# Detection Validation

## Objective

Validate the Sigma rule against the imported Sysmon dataset to confirm detection of suspicious Rundll32 execution.

---

## Detection Query

The Sigma rule was converted into Splunk SPL and executed against the imported dataset.

The detection successfully identified:

- rundll32.exe execution
- advpack.dll invocation
- RegisterOCX usage
- Parent process cmd.exe

---

## Validation Result

Status: ✅ Successful

The detection returned the expected suspicious process creation event.

---

## Important Note

The imported Sysmon dataset did not expose the execution arguments as a dedicated field after ingestion.

The suspicious command:

advpack.dll,RegisterOCX c:\Windows\System32\calc.exe

was present within the raw event and was therefore validated using raw event inspection.

The following fields were successfully extracted:

- Image
- ParentImage
- ProcessId
- ParentProcessId

The remaining suspicious execution arguments were validated directly from the raw event to preserve the integrity of the detection.
