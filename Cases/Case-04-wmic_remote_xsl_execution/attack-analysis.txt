# Attack Analysis

## Overview

The observed activity demonstrates suspicious use of the Windows WMIC utility with a remotely hosted XSL file.

The activity is notable because a legitimate Windows utility is being used to retrieve and process an external XSL resource.

---

## Observed Attack Chain

```text
cmd.exe
   |
   v
wmic.exe
   |
   v
process list /format:<remote XSL>
   |
   v
Remote XSL resource
   |
   +----> XSL file creation
   |
   +----> MSXML3.dll loaded
   |
   +----> Outbound network communication
