# Attack Analysis

## Overview

The dataset contains a Windows Event ID 7045 indicating installation of a new Windows service.

The service is configured to execute the Windows command interpreter (`%COMSPEC%`) and write to a named pipe while running under the **LocalSystem** account.

---

## MITRE ATT&CK

| Technique | ID |
|-----------|----|
| Create or Modify System Process: Windows Service | T1543.003 |

**Tactic**

- Persistence

---

## Detection Opportunities

SOC analysts should investigate services that:

- Invoke `%COMSPEC%`
- Execute shell commands using `/c`
- Reference named pipes
- Run under the `LocalSystem` account
- Have unusual service names or command lines

---

## Analyst Assessment

The observed service configuration is unusual for legitimate Windows services. Although the dataset contains only a single service installation event, the command shell, named pipe reference, and LocalSystem account make the activity worthy of further investigation.
