| Field | Value |

---

## Service Command

```text
%COMSPEC% /c ping -n 1 127.0.0.1 >nul && echo 'WinPwnage' > \\.\pipe\WinPwnagePipe
```

The service launches the Windows command interpreter and references a named pipe instead of executing a standard application directly.

---

## Suspicious Indicators

- Windows Event ID 7045
- `%COMSPEC%`
- `/c`
- Named Pipe (`\\.\pipe\WinPwnagePipe`)
- LocalSystem account

---

## Conclusion

The event shows installation of a Windows service configured to execute shell commands while interacting with a named pipe under the LocalSystem account. This behavior is uncommon for legitimate services and should be investigated as a potential persistence mechanism.
