# Event Analysis

## Event 1 — File Create

### Event ID

11

### Description

Sysmon detected the creation of a new executable.

### Key Evidence

Image:

C:\Windows\System32\cmd.exe

TargetFilename:

C:\program.exe

RuleName:

PrivEsc – Potential PrivEsc via Unquoted Service

### Why It Is Suspicious

A file named `C:\program.exe` is a well-known indicator of an Unquoted Service Path attack.

Attackers intentionally place this executable in the root of the system drive because Windows may execute it before the legitimate service executable when quotation marks are missing from the service path.

---

## Event 2 — Process Create

### Event ID

1

### Description

Sysmon detected execution of the attacker-controlled executable.

### Key Evidence

Image:

C:\program.exe

ParentImage:

C:\Windows\System32\services.exe

User:

NT AUTHORITY\SYSTEM

IntegrityLevel:

System

RuleName:

PrivEsc – Potential Unquoted Service Exploit

### Why It Is Suspicious

The Windows Service Control Manager (`services.exe`) launched the malicious executable instead of the intended service binary.

Execution under **NT AUTHORITY\SYSTEM** confirms that the attacker successfully obtained elevated privileges.

---

## Attack Summary

The investigation identified two correlated Sysmon events:

1. Creation of `C:\program.exe`.
2. Execution of `C:\program.exe` by `services.exe` as `NT AUTHORITY\SYSTEM`.

Together, these events demonstrate a successful Unquoted Windows Service Path privilege escalation attack and provide strong evidence for detection and validation.
