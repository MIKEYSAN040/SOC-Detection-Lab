/*
Detection: Unquoted Windows Service Path Privilege Escalation

Data Source:

The Sysmon EVTX attack sample was imported into Splunk
using the "detections04" index.

EventCode=11:

Sysmon Event ID 11 records File Create events,
which are used to detect the creation of a malicious
payload (C:\program.exe) commonly associated with
Unquoted Windows Service Path privilege escalation.

EventCode=1:

Sysmon Event ID 1 records Process Creation events,
which are used to detect execution of the malicious
payload by the Windows Service Control Manager
(services.exe).
*/


/* Detection Query */

index=detections04
(
    (EventCode=11 Image="*\\cmd.exe" TargetFilename="C:\\program.exe")
    OR
    (EventCode=1 Image="C:\\program.exe" ParentImage="*\\services.exe")
)


/*
Validation Note:

The Sysmon EVTX sample was indexed successfully.

The matching Sysmon events confirmed the presence of:

Event ID 11
-------------
- cmd.exe
- TargetFilename: C:\program.exe
- RuleName: PrivEsc - Potential PrivEsc via Unquoted Service

Event ID 1
-------------
- Image: C:\program.exe
- ParentImage: C:\Windows\System32\services.exe
- User: NT AUTHORITY\SYSTEM
- Integrity Level: System

These indicators validate the Sigma detection logic
for Unquoted Windows Service Path Privilege Escalation.
*/


/* Investigation Query */

index=detections04
(
    EventCode=11 TargetFilename="C:\\program.exe"
)
OR
(
    EventCode=1 Image="C:\\program.exe"
)
| table _time host EventCode RuleName Image ParentImage CommandLine TargetFilename User IntegrityLevel ProcessGuid ParentProcessGuid
| sort _time
