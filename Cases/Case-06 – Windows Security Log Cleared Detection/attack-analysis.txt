# Attack Analysis

## ATT&CK Technique

**Technique:** T1070.001

**Name:** Indicator Removal on Host: Clear Windows Event Logs

**Tactic:** Defense Evasion

---

## Description

Windows Security Event ID 1102 indicates that the Security Event Log has been cleared.

Attackers frequently clear Windows Event Logs after performing malicious activities such as privilege escalation, credential theft, persistence establishment, or lateral movement. Clearing logs removes forensic evidence and complicates incident response.

## Impact

Successful clearing of Security Logs may remove evidence related to:

- Authentication events
- Privilege escalation
- Malware execution
- Lateral movement
- User activity
- Administrative actions
