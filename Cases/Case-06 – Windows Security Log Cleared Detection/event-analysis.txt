# Event Analysis

## Event Summary

Event ID

1102

Description

The Windows Security Event Log was cleared.

---

## Important Fields

- Event ID
- Time
- Computer Name
- Subject User
- Subject Domain
- Security Identifier (SID)
- Logon ID

---

## Analysis

Windows generated Event ID 1102 immediately after the Security Event Log was cleared.

The event records the account responsible for clearing the log along with the associated Logon ID and Computer Name.

This activity is considered highly suspicious because attackers frequently remove Security Logs to erase evidence of malicious activity.

---

## Related Events

Event ID 4663

Registry access events generated by svchost.exe running as LOCAL SERVICE.

These events represent normal Windows registry read operations and are not considered malicious.

---

## Conclusion

The primary suspicious event within this dataset is Event ID 1102.

No evidence was found that Event ID 4663 represented malicious registry modifications.
