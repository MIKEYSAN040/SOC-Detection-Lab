/*
Detection: Active Directory Discovery Using BloodHound Enumeration

Data Source:

The Windows Security EVTX attack sample was imported into Splunk
using the "detections06" index.

EventCode=5145:

Windows Security Event ID 5145 records Detailed File Share
access events, which are used to detect suspicious access
to Active Directory Remote Procedure Call (RPC) interfaces
through the administrative IPC$ share.

The detection focuses on RPC interfaces commonly queried by
BloodHound during Active Directory enumeration.
*/


/* Detection Query */

index=detections06 EventCode=5145
| rex field=_raw "Share Name:\s+(?<ShareName>.*?)\s+Share Path:"
| rex field=_raw "Relative Target Name:\s+(?<RelativeTargetName>.*?)\s+Access Request Information:"
| rex field=_raw "Account Name:\s+(?<AccountName>.*?)\s+Account Domain:"
| rex field=_raw "Source Address:\s+(?<SourceAddress>.*?)\s+Source Port:"
| search ShareName="*IPC$*" (RelativeTargetName="samr" OR RelativeTargetName="lsarpc" OR RelativeTargetName="NETLOGON" OR RelativeTargetName="srvsvc")


/*
Validation Note:

The Windows Security EVTX sample was indexed successfully.

The matching Windows Event ID 5145 events confirmed the presence of:

- IPC$ Administrative Share
- samr
- lsarpc
- NETLOGON
- srvsvc
- Account: user01
- Source Address: 10.0.2.17

These indicators validate the Sigma detection logic
for BloodHound Active Directory discovery activity.
*/


/* Investigation Query */

index=detections06 EventCode=5145
| rex field=_raw "Share Name:\s+(?<ShareName>.*?)\s+Share Path:"
| rex field=_raw "Relative Target Name:\s+(?<RelativeTargetName>.*?)\s+Access Request Information:"
| rex field=_raw "Account Name:\s+(?<AccountName>.*?)\s+Account Domain:"
| rex field=_raw "Source Address:\s+(?<SourceAddress>.*?)\s+Source Port:"
| table _time ComputerName AccountName SourceAddress ShareName RelativeTargetName EventCode
| sort _time
