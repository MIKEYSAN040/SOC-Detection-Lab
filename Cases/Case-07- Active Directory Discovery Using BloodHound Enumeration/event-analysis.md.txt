# Event Analysis

## Event Type

### Event ID

5145

### Description

Windows Security Event ID 5145 records attempts to access network share objects.

---

## Key Evidence

User:

user01

Source Address:

10.0.2.17

Share:

IPC$

RPC Interfaces Accessed:

- samr
- lsarpc
- NETLOGON
- srvsvc

---

## Why It Is Suspicious

The administrative `IPC$` share is commonly used for legitimate remote administration. However, rapid and repeated access to several RPC endpoints from the same host and account is characteristic of automated Active Directory reconnaissance.

Each endpoint contributes different information:

- **samr** – User and group enumeration.
- **lsarpc** – Security policy and SID enumeration.
- **NETLOGON** – Domain controller and authentication information.
- **srvsvc** – Server and share enumeration.

The sequence of requests indicates systematic collection of Active Directory information rather than routine administration.

---

## Attack Summary

The investigation identified repeated Windows Event ID 5145 events originating from the same user account and source host.

The attacker accessed multiple RPC interfaces through the administrative `IPC$` share to enumerate users, groups, security information, domain services, and servers.

This behavior is consistent with BloodHound Active Directory discovery and maps to the MITRE ATT&CK Discovery tactic.
